# SlabStrikers 🏓

A real-time, competitive 2-player multiplayer paddle game built with Node.js, Express, and Socket.io. 

## Features
* **Real-time Multiplayer:** Low-latency syncing using Socket.io.
* **Lobby System:** Players can create and join custom room names.
* **Dynamic Gameplay:** Paddles shrink slightly upon hitting the ball, and the ball incrementally speeds up.
* **Win Condition:** First player to reach 10 points wins the match.
* **Neon UI:** Custom glowing canvas graphics and responsive controls.
